## 一、产品要做成什么样

Teemo 助手要成为你的**私人设计助理**。

你在对话框里用大白话说想做什么（生图、洗图、反推提示词、收进素材库、做类似的图），Teemo 先听懂，再调用合适的 Skill 和工作流，把结果直接回给你。

三条原则：

1. **对话是入口**。尽量少去翻设置、翻 ComfyUI 节点。
2. **电脑干活，手机遥控**。生图、视频始终在这台 Windows 电脑上跑。
3. **个人库和公司库分开**。你自己的素材库是私人库；DesignHub 仍是团队库。

你的电脑：i9-14900K、64G 内存、RTX 4070 Ti 12G、Windows 11。后面视频和工作流参数按这台机器来配。

## 三、最近刚做完、还要你帮忙验证的

这些是最近几天在开发目录里改过的，有的需要你刷新或重启后才能稳定。

| 事项 | 改了什么 | 你这边怎么确认 |
|------|----------|----------------|
| ComfyUI 设置页精简 | 不再让你填 Checkpoint、宽高、步数、CFG、负向提示词（这些跟工作流走） | 打开设置 → ComfyUI，应只看到连接和工作流；下面有 Teemo 自动识别的输入/输出 |
| PromptManager 独立启动 | 不必先开 ComfyUI 也能打开提示词库（默认 8199；8188 已有则直接打开） | 桌面或 `I:\ComfyUI\Teemo-PromptManager.exe` 能打开后台，提示词还在 |
| 打开工作流复用已开窗口 | 「在 ComfyUI 中打开当前工作流」尽量不再新开一个空白页 | ComfyUI 画布 + PromptManager 后台都 **Ctrl+F5** 后再试 |
| 缩略图裂图 | 瀑布流优先用缩略图、限并发、失败重试 | 同样 Ctrl+F5；若仍裂，需要重启一次 ComfyUI 再看 |
| 升级规划去掉钉钉 | 规划文档不再写钉钉真实 API / 闭环 | 已改完，无需操作 |

## 五、后续三条主线

### 方向 A：对话驱动（Skill × 工作流）

你说：用某个 Skill 生成什么样的图。  
Teemo 自动：选 Skill → 按 Skill 写提示词 → 选对工作流 → 生图或视频 → 结果回聊天。

也支持：丢图反推提示词、丢图按工作流洗图。说不清楚时先问一句，不乱猜。

### 方向 B：个人素材库

随手丢一张好看的图，说「加到我的素材库」。  
Teemo 识别、打标、分类、收进去。  
库大了以后：你说想做某种类似的图，Teemo 给参考建议，并生成一张 demo。

这是**私人库**，不和 DesignHub 混。

### 方向 C：手机连电脑

手机能说话、传图、看结果。  
真正生图、洗图、入库仍在电脑上完成。  
不同步：让手机自己跑 ComfyUI。

## 六、分阶段做什么（按这个顺序）

每一阶段做完都能单独拿来用，再进下一阶段。

### T1　对话里出图（下一件立刻做）

**你能感到的变化：**  
说「用 XX Skill 做一张……图」，聊天里直接出图，不用自己拷提示词去 ComfyUI。

**要做的事：**

1. 给每条导入的工作流打用途标签：文生图 / 洗图 / 反推 / 视频 / 人像 / 产品……
2. 相关 Skill 写清：适用哪条工作流、提示词怎么写、要不要参考图。
3. 听懂「用 Skill 出图」「指定工作流出图」。
4. 流水线：听懂 → 选 Skill → 写提示词 → 填进工作流 → 交给 ComfyUI → 把图发回来。
5. 工作流接口对不上时，用中文告诉你缺哪个口，不报一串英文。

**完成标准：**  
至少 1 个 Skill + 1 条你常用的工作流，从一句话到出图，全程在聊天里完成。

**当前状态：还没开工。** 点头后先写 T1 执行说明（接哪些 Skill、默认哪几条工作流、怎么说话才算出图）。

---

### T2　看图：反推提示词、洗图

**你能感到的变化：**  
丢图 + 一句话，就能得到提示词，或按指定工作流洗完发回。

**完成标准：**  
同一张参考图，能分别完成「只要提示词」和「按某工作流洗一张」。  
同时修好认知误记。

**当前状态：未开始。** 依赖 T1 的工作流调用先稳定。

---

### T3　个人素材库：一句话入库

**你能感到的变化：**  
丢图说「加到素材库」，自动打标分类，能在 Teemo 里找回来。

建议目录仍放在 `D:\Teemo助手` 下单独文件夹，例如 `Teemo-素材库`。  
不自动上传公司 DesignHub。

**完成标准：**  
丢 1 张图 +「加到我的素材库」，刷新后能按标签找到它。

**当前状态：未开始。**

---

### T4　用素材库做类似图：建议 + demo

**你能感到的变化：**  
说「做一张类似 XX 的图」，Teemo 先给参考和做法，再出 1 张小样。

第一版用标签/分类找参考，不必上复杂的以图搜图库。库太少时如实说明，不编造。

**完成标准：**  
库里有一批同类图时，能给出参考列表 + 1 张可打开的 demo。

**当前状态：未开始。**

---

### T5　视频工作流

**你能感到的变化：**  
对话里能提交视频工作流，完成后把视频或预览回给你。  
排队/进度能看见；显存和时长按 4070 Ti 12G 给安全默认值。

**完成标准：**  
一条常用视频工作流能从聊天跑通并取回结果。

**当前状态：未开始。** 依赖 T1。Skill 包已经在，缺的是聊天提交和回传。

---

### T6　手机连电脑

**你能感到的变化：**  
同一 Wi‑Fi 下，手机发「用 XX Skill 生一张图」，电脑出图后手机能看到。

第一版只做遥控器：电脑没开或 ComfyUI 没开时，手机会明确说「电脑端未就绪」，不假装成功。  
完整云同步、多设备离线、账号体系更后面再说。

**当前状态：未开始。**
