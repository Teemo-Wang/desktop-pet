# Teemo 升级规划

日期：2026-08-13  
适用产品：Teemo 助手（当前正式版 1.3.2，Windows 桌面端）  
这份文档给 Teemo 本人看：先说现在有什么，再说以前规划过但还没做成的，再把新方向排进可执行的阶段。

---

## 一、产品目标

Teemo 助手要成为你的**私人设计助理**：

你在对话框里用大白话说想做什么（生图、洗图、反推提示词、收进素材库、做类似的图），Teemo 先理解意图，再调用合适的 Skill 和工作流，把结果直接回给你。电脑是主力；手机连上后，能用同一套能力，不另起炉灶。

三条原则：

1. **对话是入口**。尽量少让你去翻设置、翻节点。
2. **电脑干活，手机遥控**。ComfyUI 生图/视频始终在这台 Windows 电脑上跑。
3. **个人库和公司库分开**。你的素材库是 Teemo 私人库；DesignHub 仍是团队库。

## 二、现在已经有的（基线，不再当新功能规划）

这些已经能用，后续是增强，不是从零开始：

| 能力 | 现在能做什么 |
|------|----------------|
| 聊天 | 多模型对话、流式回复、规划模式、本地文件读写（需批准） |
| Skill | 可导入、切换、按规则写提示词 |
| ComfyUI | 本机连接、导入 API JSON、聊天生图、结果回聊天并本地存档 |
| 看图 | 聊天里可以丢图；有音视频分析入口 |
| 灵感 | 本地文件夹、Eagle 只读库、按关键词检索参考 |
| 认知 | 「Teemo 对我的了解」会从对话里记偏好（目前会误把长提示词也记进去，要改） |
| 桌宠 | 拖拽、点击打开面板、Windows 安装包、改完自动安装重启 |
| 语雀 | 可读团队文档，作为设计规范参考 |

P0～P5 的底层安全框架已经封板。下一阶段不再做「再加一层权限框架」，而是把**设计生产力**做完整。

## 四、这次新增的三个方向（必须写进主线）

### 方向 A：对话驱动的 Skill × 工作流

你在对话框说：用某个 Skill 生成什么样的图。  
Teemo 自动：选 Skill → 按 Skill 写提示词 → 选对工作流 → 生图或视频 → 把结果发回聊天。

也支持：

- 丢一张图，按某风格 / 某工作流**反推提示词**
- 丢一张图，按某工作流**洗图**
- 意图含糊时先问一句，不乱猜

### 方向 B：个人素材库

随手丢一张好看的图，说「加到我的素材库」。  
Teemo 识别、打标、分类、收进去。

库大了以后：你说想做某种类似的图，Teemo 给出参考建议，并生成 demo。

这是**私人库**，不要和 DesignHub 混在一起。

### 方向 C：手机与电脑同步

手机连上后，能说话、传图、看结果。  
真正生图、洗图、入库仍在电脑上完成。  
同步的是：聊天、Skill、工作流配置、素材库索引和结果。  
不同步：让手机本地跑 ComfyUI。

## 五、分阶段落地（按这个顺序做）

每一阶段都要能单独拿来用，做完再进下一阶段。

### T1　对话里：Skill → 提示词 → 工作流 → 出图（最先做）

**你能感到的变化：**  
说「用 XX Skill 做一张……图」，聊天里直接出图，不用自己拷提示词去 ComfyUI。

**要做的事：**

1. 给每条导入的工作流打上用途标签：文生图 / 洗图 / 反推 / 视频 / 人像 / 产品……
2. 每个相关 Skill 写清：适用工作流、提示词怎么写、要哪些输入（纯文字 / 要参考图）。
3. 聊天意图增加：`用Skill出图`、`指定工作流出图`。
4. 流水线：理解意图 → 选 Skill → 生成提示词 → 写入工作流对应节点 → 提交 ComfyUI → 回传图片。
5. 工作流接口识别失败时，用中文告诉你缺哪个口，而不是报英文错误。

**完成标准：**  
至少 1 个 Skill + 1 条你常用的工作流，从一句话到出图，全程在聊天里完成。

---

### T2　看图：反推提示词、洗图

**你能感到的变化：**  
丢图 + 一句话，就能得到提示词，或按指定工作流洗完发回。

**要做的事：**

1. 反推：看图 → 按目标 Skill/工作流的格式输出提示词（可先不出图）。
2. 洗图：看图 + 目标风格/工作流 → 图生图 → 回传。
3. 意图分开：只反推 / 只洗图 / 洗完再按 Skill 再生一张。
4. 修认知收集：长提示词、反推结果**不要**再自动写进「Teemo 对我的了解」。只有你明确说「记住我喜欢……」才记。

**完成标准：**  
同一张参考图，能分别完成「只要提示词」和「按某工作流洗一张」两种操作。

---

### T3　个人素材库：一句话入库

**你能感到的变化：**  
丢图说「加到素材库」，自动打标分类，能在 Teemo 里找回来。

**要做的事：**

1. 私人库目录（建议仍放在 `D:\Teemo助手` 下单独文件夹，例如 `Teemo-素材库`）。
2. 入库动作：复制原图、写索引（文件名、来源会话、时间、自动标签、你指定的分类）。
3. 自动识别：主体、风格、色彩、是否人像/产品/场景；标签可改。
4. 和 PromptManager / 灵感文件夹打通浏览，但入库指令以聊天为准。
5. 和 DesignHub 隔离：不自动上传公司库。

**完成标准：**  
丢 1 张图 +「加到我的素材库」，刷新后能按标签找到它。

---

### T4　用素材库做类似图：建议 + demo

**你能感到的变化：**  
说「做一张类似 XX 的图」，Teemo 先给参考和做法，再出 1 张小样。

**要做的事：**

1. 先按标签/分类/简单相似度找 3～8 张参考（第一版不必上向量库）。
2. 根据参考选出 Skill + 工作流，说明为什么选。
3. 生成 1 张 demo 回聊天；你说继续再出更多。
4. 库太少时如实说明，不编造「很像」的参考。

**完成标准：**  
库里至少有一批同类图时，能给出参考列表 + 1 张可打开的 demo。

---

### T5　视频工作流

**你能感到的变化：**  
对话里能提交视频工作流，完成后把视频或预览回给你。

**要做的事：**

1. 导入并标记视频工作流（时长、是否要参考图/音频）。
2. 聊天显示排队/进度；完成后可打开文件。
3. 显存和时长按你这台 4070 Ti 12G 给默认安全参数。

**完成标准：**  
一条常用视频工作流能从聊天跑通并取回结果。  
依赖：T1 的工作流调用已经稳定。

---

### T6　手机连电脑

**你能感到的变化：**  
手机连上这台电脑后，能发文字/图片，看到和电脑端一样的结果。

**要做的事：**

1. 第一版做「遥控器」：手机 ↔ 已打开的电脑 Teemo，不在手机上跑 ComfyUI。
2. 同步聊天、Skill、工作流列表、素材库索引、生成结果。
3. 电脑休眠或 ComfyUI 没开时，手机要说清楚「电脑端未就绪」，不要假成功。
4. 完整云同步、多设备离线、账号体系放到更后面。

**完成标准：**  
同一 Wi‑Fi 下，手机发「用 XX Skill 生一张图」，电脑出图后手机能看到。

## 七、明确先不做

避免范围膨胀：

- 不让 Teemo 变成通用 ComfyUI 编辑器（节点画布仍在 ComfyUI 里改）
- 不在普通聊天里开放删文件、随意执行命令、乱改 Git
- 不把公司 DesignHub 和个人素材库混成一个库
- 不做「手机离线本地生图」
- 第一版不上复杂多 Agent 分工、全网爬灵感、NAS 自动扫描

---

3. T3 个人素材库入库  
4. T4 类似图建议 + demo
